# First human play of OpenSupCom on this Mac (2026-10-16)

Build: upstream `df11a927`, unmodified, `~/Projects/OpenSupCom/build/play/opensupcom`,
started with `--windowed 2560 1440`, then maximized by JStar. Retail GOG data.
Evidence: `~/.local/state/opensupcom/logs/opensupcom.log` (20:34:30 to 20:44:29),
the replay in `~/Documents/My Games/Gas Powered Games/...`, JStar's screenshot and notes.

Driver: Homebrew MoltenVK through vcpkg's loader (before the 2026-10-17 switch to
KosmicKrisp); re-check the team-colour tint on KosmicKrisp.

## Observed

- Skirmish against the AI on SCMP_039, 5,045 ticks (8.4 game minutes); normal exit,
  replay written, no crash report, 0 `[error]` lines.
- JStar: loads quickly (much faster than CrossOver), window maximizes and fills the
  screen, smooth, "feels like 120 fps". Frame rate is not measured: the log has no
  frame timing.
- Display: Studio Display XDR, 120 Hz maximum (`NSScreen.maximumFramesPerSecond`),
  set to "looks like" 2880x1620 at 2x backing. So 120 fps is possible on the display
  JStar plays on.
- HUD and menus draw very small on the 5K display (screenshot). OSC has no UI scale
  (no scale handling in `src/`, only framebuffer sizes). Retail `options.lua` has no
  UI Scale option; FAF's has one (`ui_scale`, restart required).
- Anti-aliasing is greyed out ("Off"). Three warnings, each when the Video tab opens:
  `options.lua:481: access to nonexistent global variable "aaoptions"`. Retail line
  477 is `aaoptions = GetAntiAliasingOptions()`, so OSC's `GetAntiAliasingOptions`
  most likely returns nothing (inferred, not checked in OSC's source).
- Primary and Secondary Adapter read "Command Line Override": the window size came
  from the command line. By design.
- JStar saw possible glitches in unit colouring and possibly effects. No log evidence.
  A reference from the original exists: `work/logs/screens/ref-team-colour-acu-uef.png`.
- JStar (after the session): every sound, effect and music track played clearly,
  no distortion. The window title showed 120 fps. The team colour on the ACU was
  solid red at spawn and faded to a dim pink once it moved; other mobile units did
  the same. No visible degradation in effects.

## Not observed

Frame timing measured by the engine (the 120 fps is the title bar's figure), the
tech tree past the early game.

## What it changes

- Interface scale on Retina is the first fix ([roadmap.md](../roadmap.md) M1).
- The 5K display runs at 120 Hz, so 120 fps can be shown on it.
- The anti-aliasing options failure is a small, concrete fix (M1).
- The team-colour fade is the first case for "replay plus screenshot at a tick" (M3).
